# ChatBot 
A simple command-line based chatbot built using the C programming language.
This project demonstrates basic conversation handling, conditional responses, string matching, and interactive input/output in C.

Features
Simple text-based conversation

Responds to basic greetings and questions

Keyword-based reply system

Loop-based continuous chatting until user exits 

Technologies Used

C Programming Language

Standard Input/Output (stdio.h)

String Handling (string.h)

How It Works: 
1. The program runs in a loop and waits for user input.

2. It checks the input against a set of predefined keywords (like “hi”, “hello”, “bye”, “name”, etc.).

3. If a keyword matches, the chatbot prints a relevant response.

4. If the message doesn’t match any keyword, the bot gives a default reply.

5. Typing "bye" ends the conversation.
